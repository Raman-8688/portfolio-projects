## 📌 Executive Summary

Welcome to **`real-portfolio-project`** — a high-performance **React 18 + Vite** single-page application built specifically for **Ramanjaneyulu Boya** to showcase MNC-level engineering competency for enterprise technical interviews (targeting top tier MNCs like TCS, Infosys, Wipro, Accenture, Cognizant, LTI Mindtree, Tech Mahindra, Amazon, Oracle, Microsoft).

This project features:
* **Interactive HTML5 Canvas Constellation Particle Mesh** with real-time cursor physics.
* **3D Perspective Tilt Micro-Interactions** on mouse hover for glass cards & profile elements.
* **MNC Technical Interview Q&A & Architecture Cheat Sheet Modal**.
* **Built-in Interactive DevOps CLI Terminal Simulator** supporting live commands (`help`, `skills`, `architecture`, `projects`, `curl /health`, `docker-compose`, `export-resume`, `clear`).
* **Project Deep-Dive Modals** with system architecture specs, DB design highlights, and actual Java/Spring Boot code snippets.
* **ATS Resume Viewer & Quick PDF Exporter Modal**.
* **Synthetic Web Audio UI Sound Effects Engine** (zero external sound file dependencies).
* **Reading Progress Bar & Scroll-to-Top Circular Percentage Ring**.
